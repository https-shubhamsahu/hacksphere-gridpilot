04 · Data & cleaning

4,000 training hours. Cleaned the same way at train and predict time.

Schema

timestamp YYYY-MM-DD HH
ambient_temp_c °C
humidity_pct %
solar_irradiance_wm2 W/m²
→ target_demand_kw kW

Cleaning

  • Normalize timestampsparse, floor to hour, sort
  • Interpolate gapstime-based, edges filled
  • Clip outliersphysical ranges per sensor
  • Dedupeone row per hour

Features

  • Hour, weekday
  • Cyclic hoursin / cos
  • Cooling / heating degrees
  • Evening window flag18–22 h
